Contract Monthly Claim System (CMCS)

The Contract Monthly Claim System (CMCS) is a multi-phase project designed to digitize and streamline the process of submitting, verifying, and approving monthly claims for contract lecturers.

CMCS - Part 1: Non-Functional Prototype This initial phase focused on designing and building the foundational front-end user interface and defining the system architecture. It serves as a visual and logical blueprint for future development.

Project Deliverables Project Plan: A comprehensive document outlining the project's scope, methodology, timeline, and an analysis of key risks and constraints.

System Design: A detailed document describing the system's architecture, including a UML diagram and a relational database model for a future live system. This justifies how the design supports core functionalities like user management and claim processing.

GUI Prototype: A user-friendly and responsive front-end built using HTML, CSS (Bootstrap), and JavaScript. This prototype simulates the user experience for three distinct roles:

Lecturer: Submits new claims.

Programme Coordinator: Verifies pending claims.

Academic Manager: Approves or rejects claims.

CMCS - Part 2: Implement a Prototype Web Application This phase transitions the project from a visual blueprint (Part 1) to a working, functional system. The goal is to implement the core business logic and features of the CMCS using a GUI UI .NET Core web application, connecting the user-friendly front-end to a basic functional backend.

Functionalities to be Implemented This phase focuses on adding the following four core functionalities:

Lecturer Claim Submission Simple & Intuitive Form: Design a form including fields for hours worked, hourly rate, and additional notes.
User Flow: Implement a straightforward layout and colour scheme to make the submission process as smooth as possible.

Action: A prominently displayed 'Submit' button for claim finalisation.

Claim Verification and Approval Workflow Role-Based View: Design a separate dashboard for Programme Coordinators and Academic Managers.
Pending Claims: This view must clearly display all pending claims requiring verification/approval.

Actionable Items: Each claim must be clearly organised and feature distinct 'Approve' and 'Reject' buttons.

Supporting Document Upload Upload Feature: Integrate an 'Upload' button into the claim submission form.
Security: Ensure uploaded files are securely stored and correctly linked to the corresponding claim.

Display: Once uploaded, the file's name should be displayed on the form.

Restrictions: Implement file size limits and restrict file types to common formats: .pdf, .docx, and .xlsx.

Transparent Claim Tracking Tracking System: Implement a mechanism that updates the status of each claim as it moves through the approval process.
Visibility: Represent the claim status clearly, either as a simple text label ('Pending', 'Approved', 'Rejected') or as a visual progress bar.
